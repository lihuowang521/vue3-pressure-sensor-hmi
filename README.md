# vue3-sensor 项目: 管道法兰压力检测智能传感器人机交互界面（毕业设计）

## 项目简介

本项目是一个基于 Vue 3 开发的**管道法兰压力检测智能传感器人机交互界面**，主要用于实时监控和管理管道法兰上的12个压力传感器数据。系统通过 MQTT 协议与 ESP32 嵌入式终端进行实时通信，支持实时数据展示、历史数据查询、数据可视化和导出等功能，为工业环境中的压力监测提供直观、高效的解决方案。

## 功能特性

### 📊 实时监控

- **12传感器圆形布局**：模拟管道法兰上均匀分布的12个压力传感器
- **实时数据更新**：每秒更新一次传感器数据
- **管道/法兰选择器**：支持多管道多法兰的切换监控
- **温度实时显示**：同步显示环境温度
- **系统参数展示**：电池电压、信号强度等

### 📈 数据可视化

- **压力趋势图表**：实时显示最近1分钟的数据曲线
- **多传感器对比**：支持3个传感器数据同图对比
- **温度折线图**：独立Y轴显示温度变化趋势
- **动态X轴滚动**：自动跟随最新数据，平滑滚动显示
- **交互式Tooltip**：悬停显示详细数据信息

### 📋 历史数据查询

- **时间范围选择**：支持快捷选择（最近1小时/6小时/24小时/30天）
- **多条件筛选**：管道、法兰、传感器多维筛选
- **数据表格展示**：分页显示历史记录
- **时区适配**：自动处理本地时间显示

### 💾 数据导出

- **CSV格式导出**：支持按条件导出历史数据
- **温度数据包含**：导出时自动包含温度字段
- **自动文件名**：生成带时间戳的文件名
- **自定义时间范围**：灵活选择导出时段

### ⚙️ 系统设置

- **MQTT连接配置**：服务器地址、端口、认证信息
- **报警阈值设置**：支持动态配置上下限报警阈值
- **采样频率配置**：可选10/50/100/500/1000 Hz
- **数据校验开关**：控制数据校验严格程度

### 🔒 智能数据校验

- **动态阈值校验**：根据配置的报警阈值实时校验
- **多字段支持**：支持 pressure1-pressure12 字段
- **缺失值处理**：自动为缺失字段设置默认值0g
- **友好警告提示**：校验失败时显示警告弹窗，不中断数据接收

## 使用说明

### 1. 实时监控界面

1. 在管道/法兰选择器中选择要监控的管道和法兰
2. 系统自动加载并实时更新12个传感器的压力数据
3. 右侧图表显示3个选定传感器的压力趋势和温度曲线
4. 底部显示系统参数和报警状态

### 2. 历史数据查询

1. 选择管道、法兰和传感器
2. 设置时间范围（支持快捷选择或自定义）
3. 点击查询按钮查看历史数据
4. 数据以表格形式展示，支持分页

### 3. 数据导出

1. 选择导出条件（管道、法兰、时间范围）
2. 点击导出按钮
3. 系统生成CSV文件并自动下载

### 4. 系统设置

1. 配置MQTT连接参数（服务器地址、端口、主题等）
2. 设置报警阈值（上下限）
3. 配置采样频率
4. 点击保存按钮保存配置

## 数据格式

### MQTT消息格式

```json
{
"pipe_id": "P001",           // 管道ID
"flange_id": "F01",          // 法兰ID
"pressure1": 120.5,          // 传感器1压力值(g)
"pressure2": 0.0,            // 传感器2压力值(g)
"pressure3": 4500.0,         // 传感器3压力值(g)
"temperature": 25.5,         // 温度(°C)
"parsed_time": "2025-04-19 22:30:16",  // 时间戳
"rssi": -55,                 // 信号强度(dBm)
"battery_voltage": 3.2       // 电池电压(V)
}
```

**支持字段**：pressure1-pressure12（缺失字段自动填充为0g）

### 数据校验规则

- 压力值范围：0-5000g（可通过设置动态调整）
- 必须包含至少一个有效的pressure字段
- 时间戳格式：YYYY-MM-DD HH:MM:SS
- 温度范围：-40°C ~ 125°C（DS18B20传感器范围）

## 硬件端数据采集（ESP32）

项目配套的嵌入式终端基于 ESP32 开发，主要特性：

- **传感器类型**：FSR压力传感器 ×3 + DS18B20温度传感器
- **ADC配置**：12位分辨率，0dB衰减
- **数据处理**：线性插值算法，干扰滤波处理
- **时间同步**：NTP时间同步（ntp.ntsc.ac.cn）
- **安全连接**：MQTT over SSL/TLS（端口8883）
- **数据上传频率**：每秒上传一次
