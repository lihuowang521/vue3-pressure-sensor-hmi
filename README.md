# 管道法兰压力智能监测系统

## 毕业设计：智能压力传感器人机交互界面设计

页面已部署到 GitHub Pages：https://lihuowang521.github.io/vue3-pressure-sensor-page/

## 项目简介

本项目面向工业管道法兰智能运维需求，设计并实现了一套**管道法兰压力智能监测系统**。系统由 **ESP32 嵌入式数据采集终端** 和 **Vue 3 前端人机交互界面** 两部分组成，二者通过 MQTT 协议实现双向数据交互。嵌入式终端负责压力与温度数据的采集、处理与上传；前端界面承担数据可视化展示、历史数据查询、远程参数配置等功能，为用户提供直观便捷的人机交互体验。

系统整体采用三层架构设计：感知采集层由 ESP32 读取 ADC 原始信号，完成信号转换与滤波处理；网络通信层通过 Wi-Fi 实现设备联网，并基于 MQTT over TLS 完成消息的加密传输与分发；人机交互层通过前端界面实现数据的实时显示、设备控制与数据记录，三层协同工作，形成一套完整的数据采集、传输与交互流程。

## 功能特性

### 实时监控

- **12 传感器圆形仪表盘布局**：模拟管道法兰上均匀分布的 12 个压力传感器
- **实时数据更新**：每秒刷新一次传感器数据
- **管道/法兰选择器**：支持多管道多法兰的切换监控
- **温度实时显示**：同步显示环境温度
- **系统参数展示**：电池电压、Wi-Fi 信号强度等

### 数据可视化

- **压力趋势图表**：实时显示最近 1 分钟的数据曲线
- **多传感器对比**：支持 3 个传感器数据同图对比
- **温度折线图**：独立 Y 轴显示温度变化趋势
- **动态 X 轴滚动**：自动跟随最新数据，平滑滚动显示
- **交互式 Tooltip**：悬停显示详细数据信息

### 历史数据查询

- **时间范围选择**：支持快捷选择（最近 1 小时 / 6 小时 / 24 小时 / 7 天 / 30 天）
- **多条件筛选**：管道、法兰、传感器三维联动筛选
- **数据表格展示**：分页显示历史记录
- **时区适配**：自动处理本地时间显示

### 数据导出

- **CSV 格式导出**：支持按条件导出历史数据，包含温度字段
- **自动文件名**：生成带时间戳的文件名
- **数据删除功能**：按条件批量删除历史数据
- **旧数据清理**：支持保留最新 N 条数据的批量清理

### 系统设置

- **采样频率配置**：可选 10 / 50 / 100 / 500 / 1000 Hz
- **报警阈值设置**：支持动态配置上下限报警阈值（0~5000g）
- **串口通信配置**：波特率、数据位、停止位、校验位
- **MQTT 连接配置**：服务器地址、端口、认证信息
- **传感器校准**：零点校准、满量程校准
- **配置持久化**：所有参数通过 localStorage 持久化存储，支持版本兼容

### 智能数据校验

- **动态阈值校验**：根据配置的报警阈值实时校验，阈值变更即时生效
- **多字段支持**：支持 pressure1-pressure12 共 12 路压力字段
- **缺失值处理**：自动为缺失字段设置默认值 0g
- **友好警告提示**：校验失败时在界面右上角弹窗提示，不中断数据接收，5 秒自动消失

## 嵌入式终端设计 (ESP32)

### 硬件配置

| 组件 | 型号 / 规格 | 数量 | 连接引脚 |
|------|------------|------|---------|
| 主控芯片 | ESP32-WROOM-32 | 1 | — |
| 压力传感器 | FSR402 电阻式薄膜压力传感器 | 3 | GPIO36 / GPIO39 / GPIO32 |
| 温度传感器 | DS18B20 数字温度传感器 | 1 | GPIO4 |
| 电源 | 3.3V DC | 1 | VDD33 / GND |

### ESP32 核心参数

| 参数 | 规格 |
|------|------|
| 处理器 | 双核 Xtensa LX6, 80~240MHz |
| SRAM / ROM | 520KB / 448KB |
| ADC 分辨率 | 12 位 SAR ADC (0~4095) |
| ADC 衰减 | 0dB (量程 0~1.1V) |
| Wi-Fi | 802.11 b/g/n |
| 工作电压 | 2.2V ~ 3.6V (典型 3.3V) |
| 工作温度 | -40°C ~ +85°C |

### GPIO 引脚资源分配

| 传感器 | ESP32 引脚 | 通道属性 | 功能说明 |
|--------|-----------|---------|---------|
| 压力传感器 1 | GPIO36 (SENSOR_VP) | ADC1_CH0 | 法兰点位 1 压力信号采集 |
| 压力传感器 2 | GPIO39 (SENSOR_VN) | ADC1_CH3 | 法兰点位 2 压力信号采集 |
| 压力传感器 3 | GPIO32 | ADC1_CH4 | 法兰点位 3 压力信号采集 |
| DS18B20 温度传感器 | GPIO4 | 通用 GPIO | 环境温度信号采集 |

> 所有压力采集引脚均选用 ADC1 通道，规避 Wi-Fi 通信对模拟信号采集的干扰。

### 核心依赖库

| 库名称 | 用途 |
|--------|------|
| `WiFi.h` | Wi-Fi 网络连接与数据通信 |
| `PubSubClient.h` | MQTT 客户端，支持消息发布与订阅 |
| `NTPClient.h` + `WiFiUdp.h` | NTP 网络时间同步 |
| `WiFiClientSecure.h` | MQTT SSL/TLS 加密传输 |
| `OneWire.h` + `DallasTemperature.h` | DS18B20 温度传感器驱动 |
| `time.h` | 标准 C 时间处理 |

```
系统上电
  │
  ▼

│                                 │
│  1. 检查 MQTT 连接 (断线自动重连) │
│  2. 同步 NTP 时间                │

│  4. 读取 3 路压力 ADC 原始值     │
│  5. 读取温度传感器               │
│  6. 浮点线性插值 + 死区滤波      │
│  7. 封装 JSON 数据包             │
│  8. MQTT 发布 (sensor/data)     │
│  9. 延迟 2 秒                    │
└─────────────────────────────────┘
```

### 压力信号处理算法

**浮点线性插值算法**：将 ADC 原始值 (0~4095) 线性映射到 0~5000g 标准压力范围。

```
P = (raw - 40) / (2800 - 40) × 5000.0
```

- 下限钳位：raw < 40 → 返回 0.0g
- 上限钳位：raw > 2800 → 返回 5000.0g
- 最终限幅：constrain(P, 0.0, 5000.0)

**死区滤波算法**：当计算压力值小于 300g 时强制归零，有效抑制 ADC 通道串扰、空载噪声和零点漂移产生的虚假数据。

## 前端界面

### 使用说明

#### 1. 实时监控界面

1. 在管道/法兰选择器中选择要监控的管道和法兰
2. 系统自动加载并实时更新 12 个传感器的压力数据
3. 右侧图表显示 3 个选定传感器的压力趋势和温度曲线
4. 右上角显示警告弹窗（数据异常时自动触发）
5. 底部显示系统参数和报警状态

#### 2. 历史数据查询

1. 选择管道、法兰和传感器 (1~12)
2. 设置时间范围（支持快捷选择或自定义）
3. 点击查询按钮查看历史数据
4. 数据以趋势图 + 表格形式展示

#### 3. 数据导出

1. 选择导出条件（管道、法兰、时间范围）
2. 点击导出按钮
3. 系统生成 CSV 文件并自动下载

#### 4. 系统设置

1. 配置采样频率、报警阈值、串口参数、MQTT 地址
2. 点击保存按钮保存配置（自动持久化到 localStorage）
3. 支持一键恢复默认配置

## 数据格式

### MQTT 消息格式 (嵌入式终端 → 前端)

```json
{
  "pipe_id": "P001",
  "flange_id": "F01",
  "pressure1": 120.5,
  "pressure2": 0.0,
  "pressure3": 4500.0,
  "pressure4": 0.0,
  "pressure5": 0.0,
  "pressure6": 0.0,
  "pressure7": 0.0,
  "pressure8": 0.0,
  "pressure9": 0.0,
  "pressure10": 0.0,
  "pressure11": 0.0,
  "pressure12": 0.0,
  "temperature": 25.5,
  "parsed_time": "2026-06-10 13:53:59",
  "rssi": -55,
  "battery_voltage": 3.2
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `pipe_id` | String | 管道标识 |
| `flange_id` | String | 法兰标识 |
| `pressure1` ~ `pressure12` | Float | 12 路压力值 (g)，范围 0~5000 |
| `temperature` | Float | 环境温度 (°C) |
| `parsed_time` | String | 采集时间戳 (YYYY-MM-DD HH:MM:SS) |
| `rssi` | Int | Wi-Fi 信号强度 (dBm) |
| `battery_voltage` | Float | 电池电压 (V) |

### 数据校验规则

- 压力值范围：0 ~ 5000g（可通过设置页面动态调整报警阈值）
- 缺失字段自动填充为 0g
- 时间戳格式：YYYY-MM-DD HH:MM:SS
- 温度范围：-55°C ~ +125°C (DS18B20 传感器范围)
